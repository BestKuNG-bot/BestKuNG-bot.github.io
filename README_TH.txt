AR แนะนำสาขาออกแบบสื่อดิจิทัล — เอกเกมและแอนิเมชัน

วิธีอัปโหลด GitHub Pages
1. แตกไฟล์ ZIP ก่อน (GitHub ไม่แตก ZIP ให้เอง)
2. อัปโหลดไฟล์ทั้งหมดและโฟลเดอร์ fonts ไว้ที่หน้าแรกของ repository BestKuNG-bot.github.io
3. รักษาชื่อไฟล์และโครงสร้างตาม ZIP แล้วกด Commit changes
4. เปิด https://bestkung-bot.github.io/faculty_ar.html?v=2 บน Safari หรือ Chrome มือถือ
5. กดเริ่มสำรวจด้วย AR และอนุญาตใช้กล้อง
6. เปิด tracker.png บนอีกเครื่อง หรือพิมพ์ลงกระดาษ แล้วส่องทั้งภาพ
7. เมื่อพบรูป มาสคอตจะโบกมือและการ์ดจะปรากฏ กดปุ่มด้านล่างเพื่อเปลี่ยนหัวข้อ

ไฟล์หลัก
faculty_ar.html = หน้าเว็บ
faculty.mind = ข้อมูลตรวจจับรูปที่คุณส่งมา (targetIndex: 0)
mascot.glb = มาสคอตพร้อมแอนิเมชัน Waving จาก FBX ที่คุณส่งมา
tracker.png = รูปถาปัตย์ ศาลายาที่ผู้ใช้ระบุล่าสุด (ไม่ตัดขอบ)
mascot_preview.png = ภาพมาสคอตในหน้าต้อนรับ
fonts.css และโฟลเดอร์ fonts = ฟอนต์ไทย Prompt / Noto Sans Thai
qr_faculty.png = QR เปิด URL ของหน้าเว็บเวอร์ชัน 2 (จะใช้ได้เมื่ออัปโหลดแล้ว)

เนื้อหาใช้ชื่อคณะ สาขา เอก และอาชีพที่ผู้ใช้ระบุ ไม่มีชื่อมหาวิทยาลัยเพราะยังไม่ได้ระบุ
หัวข้องานสร้างสรรค์เป็นตัวอย่างงานในสายเกมและแอนิเมชัน ไม่ได้อ้างว่าเป็นรายวิชาในหลักสูตร
ยังไม่มีการเพิ่มเว็บไซต์รับสมัครหรือเบอร์ติดต่อ

การ์ดอยู่ด้านล่างหน้าจอ อ่านได้สะดวก ขณะที่มาสคอตติดตามรูปจริง
เมื่อรูปหลุดจากกล้อง การ์ดยังคงอยู่ให้อ่านต่อ พร้อมข้อความส่องรูปอีกครั้ง

ดูตัวอย่างการจัดหน้าข้อมูลโดยไม่เปิดกล้อง: faculty_ar.html?preview=1

ต้องใช้อินเทอร์เน็ตเพื่อโหลด A-Frame, MindAR และ aframe-extras จาก CDN
ฟอนต์และไฟล์โมเดลเก็บอยู่ในชุดไฟล์นี้แล้ว
กล้องประมวลผลบนอุปกรณ์ หน้านี้ไม่มีการบันทึกหรืออัปโหลดภาพกล้อง

สถานะการตรวจ
ตรวจไฟล์ GLB มีโครงกระดูกและ animation Waving แล้ว
คอมไพล์ tracker เป็น .mind สำเร็จแล้ว
การจับรูปจริง ความนิ่ง และตำแหน่งมาสคอตต้องทดสอบบนมือถือหลังอัปโหลด

ตรวจหน้าต้อนรับ การ์ดทั้ง 3 หัวข้อ ปุ่มช่วยเหลือ และขนาดจอ 360 / 390 / 430 / 1280 px ผ่านแล้ว
ทดสอบด้วยภาพกล้องจำลอง: ตรวจพบ tracker, โหลด GLB, animation mixer ทำงาน, การ์ดขึ้น และสถานะหลุด/พบรูปทำงาน

เวอร์ชัน 2: เปลี่ยน tracker เป็นภาพถาปัตย์ ศาลายา ขนาด 960 × 960 และคอมไพล์ .mind ใหม่
กรอบสแกนเปลี่ยนเป็นสี่เหลี่ยมจัตุรัส และเพิ่ม ?v=2 ให้รูป/ข้อมูลตรวจจับเพื่อป้องกันไฟล์เก่าค้าง
ทดสอบภาพจำลองด้วย tracker ใหม่ผ่านแล้ว ส่วนมือถือจริงยังต้องทดสอบหลังอัปโหลด
